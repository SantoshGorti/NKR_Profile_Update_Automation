WHAT WAS BUILT:

A Python-based Selenium automation tool that automatically updates your
Naukri.com profile headline once every hour to improve recruiter visibility.

The tool intelligently rotates through 5 professional headline variations,
avoiding consecutive repeats, with comprehensive error handling, logging,
and background execution support.

🎓 ARCHITECTURE OVERVIEW:

Main Workflow:
  1. LOGIN & AUTHENTICATE
     ├── Load credentials from .env
     ├── Initialize WebDriver
     └── Login to Naukri

  2. NAVIGATE TO PROFILE
     ├── Go to profile page
     ├── Wait for page load
     └── Locate headline field

  3. UPDATE HEADLINE
     ├── Select random headline (avoid repeats)
     ├── Clear existing text
     ├── Enter new headline
     └── Click save button

  4. VERIFY & SAVE
     ├── Wait for save completion
     ├── Verify headline changed
     └── Log results

  5. SCHEDULE & REPEAT
     ├── Log execution (success/failure)
     ├── Save to JSON history
     ├── Take screenshot on error
     └── Wait 1 hour for next execution

Module Dependencies:
  main.py ─┬─ auth.py (authentication)
           ├─ profile.py (profile updates)
           ├─ scheduler.py (scheduling)
           │  └─ headlines.json
           ├─ logger.py (logging)
           │  └─ config.py
           └─ config.py (configuration)
              └─ .env (credentials)
